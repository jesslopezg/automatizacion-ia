# AI Automation Lab — UTB–ETD

Sitio web estático educativo para GitHub Pages. Incluye simulador de atención al cliente, guía práctica, miniquiz y guía docente.

## Uso
Abrir `index.html` o activar GitHub Pages desde Settings → Pages → Deploy from a branch → main / (root).

## Alcance
La demo funciona localmente y no ejecuta un modelo real. Para la práctica, el alumnado conectará Google Forms, Sheets, Gemini API, Apps Script y borradores de Gmail.

## Seguridad
No subir claves API, no procesar datos personales reales y no enviar automáticamente respuestas generadas sin revisión.
